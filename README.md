# BharatPDF / DesiPDF 🇮🇳📄

> **India's Private, Instant & In-Browser Document Engine Suite**  
> Complete 32-in-1 Document Engines + Essential Government (Sarkari) & Citizen Presets.

---

## 🌟 Why DesiPDF / BharatPDF?

- **100% Client-Side Privacy**: Runs completely inside your browser memory (RAM sandbox). No files are uploaded to any server.
- **DPDP Act (2023) Compliant**: Zero data retention, zero telemetry, zero accounts required.
- **Tailored for India**: Built specifically for students, cyber cafes, government exam applicants, and citizens dealing with strict portal criteria (UPSC, SSC, NTA/NEET, IBPS, Aadhaar KYC).

---

## 🏛️ Essential Government & Citizen Presets

| Preset | Target & Criteria | Purpose |
| :--- | :--- | :--- |
| **UPSC Photo & Sign Resizer** | Photo: 350×350 px (<50KB)<br>Signature: 350×140 px (<20KB) | Exact resampler for Civil Services & NDA portals |
| **SSC CGL / CHSL 50KB Compress** | Photograph <50KB, Signature <20KB | Binary-search cruncher meeting strict size thresholds |
| **NTA / NEET Form PDF** | Compile under 300KB | Combines postcard photo, thumb impression, & certificates |
| **Aadhaar & KYC Masking Stamp** | Masks first 8 digits + Stamps attestation notice | Legal compliance for bank KYC, SIM registration, and rental verification |
| **IBPS Document Format Studio** | Thumb: 10–20KB<br>Handwritten declaration: 50–100KB | Standard bank recruitment formats |
| **Marksheet Dossier Merger** | Chronological 10th + 12th + Degree | Creates clean, continuous admissions dossiers |

---

## ⚙️ Complete 32 Document Engines

1. **Organize**: Merge PDF, Split PDF, Remove Pages, Extract Pages, Organize Pages, Scan to PDF (Webcam Capture).
2. **Optimize**: Compress PDF (Object stream deflation), Repair PDF (Xref sanitizer).
3. **Convert TO PDF**: JPG to PDF, Word/Text to PDF, PowerPoint to PDF, Excel to PDF, HTML to PDF, EPUB/Text to PDF.
4. **Convert FROM PDF**: PDF to JPG, PDF to Text/Word, PDF to PowerPoint, PDF to CSV/Excel.
5. **Edit**: Annotate / Edit PDF, Rotate PDF (+90°, 180°, +270°), Page Numbers, Add Watermark, Crop PDF.
6. **Security & Signature**: Sign PDF (Interactive Canvas Pad), Protect PDF, Unlock PDF, Redact Sensitive Data, Sanitize Metadata.
7. **Specialized**: Indic OCR (Tesseract.js), PDF to PDF/A (Archival standard), Compare PDF (Page and structural check), Sarkari Resizer.

## 🚀 How to Run

1. **Install dependencies**:
   ```bash
   npm install
   ```
2. **Start the local server**:
   ```bash
   npm run dev
   ```
3. Open **`http://localhost:5173`** in your browser.
